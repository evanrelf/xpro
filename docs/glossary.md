# Glossary

The canonical words for Xpro's concepts. Use these terms, and only these, in
code, on the command line, in the app and in docs. When a new concept comes
along, name it here first. Each entry notes words to avoid where a near-synonym
is likely to creep in. To see the terms used together, read the
[story](story.md).

## Files

A file is something on disk, referred to by its path. Once read into memory it
becomes a mosaic, an image, a graph or an edit, never a "file". So in code, a
variable holding a path is named as a path, and in-memory data is named for what
it is. Command-line help can still ask for a file, by convention.

**Image file**
: A file holding a picture, such as a raw file, JPEG or PNG. Xpro never
modifies an image file it edits. Avoid "photo" as a term, though it's fine in
prose about photography.

**Raw file**
: An image file holding a camera sensor's data before development, such as a
Nikon NEF or a DNG. Write "raw" in lowercase: it describes the data (raw as
opposed to cooked), and isn't the name of a file format or an extension.

**Graph file**
: A file holding a graph on its own, such as `portra-look.xpro`.

**Edit file**
: A file holding an edit. It's a sidecar: it lives next to the image file it
edits, named after that file's full filename, so a raw file and a JPEG
with the same name get separate edit files: `DSC_4362.NEF` →
`DSC_4362.NEF.xpro-edit`.

## Graphs

**Graph**
: A directed acyclic graph of nodes that produces values, usually starting from
its inputs. A graph is pure: the same inputs and parameters always give the
same values. Avoid "recipe", "patch", "script", "workflow", "network" and
"scene".

**Edit**
: A graph with one of its inputs bound to an image file, the one its edit file
lives next to.

**Node**
: One step in a graph, such as an exposure adjustment or a demosaic.

**Node type**
: The kind of a node, such as Exposure or Demosaic. It defines the node's ports
and parameters.

**Node ID**
: A node's unique name within its graph, generated by Xpro from its node type
and a short random suffix, like `exposure_k3f9`. Never typed by hand. A node can
also have a **label**, an optional human-readable name that doesn't need to be
unique.

**Parameter**
: A setting stored on a node itself, such as an exposure's number of stops, as
opposed to a value arriving through an input.

**Port**
: A typed point on a node where a value comes in or goes out: an input or an
output. Avoid "socket" and "pin" (the viewer can be pinned to a node).

**Input**
: Where a value comes into something. A node's inputs are ports, each wired to
another node's output. A graph's inputs are data it reads from outside itself
when it's evaluated, such as an image file or standard input. They aren't part
of the graph, so the same graph can be used with any. A graph can have any
number of inputs, such as an image and a depth map to guide its sharpening.
Avoid "source".

**Output**
: A port where a value leaves a node, to be wired to other nodes' inputs.

**Wire**
: As a noun, the line from one node's output to another node's input. As a
verb, to create one: wire an output to an input. Only ports with compatible
value types can be wired together. Avoid "link" (copying versus linking),
"edge" and "pipe".

## Values

**Value**
: Anything that flows from an output to an input. Every value has a **value
type**, and every port has the value type it accepts or provides.

**Mosaic**
: A camera sensor's data before demosaicing, with one color sample per
photosite in a repeating pattern, such as a Bayer pattern. Reading a raw file
produces a mosaic.

**Image**
: A grid of pixels, carrying its color space. A **scene-referred image** holds
values proportional to light in the scene, with no upper limit. A
**display-referred image** holds values describing how things should look on a
display, within its range. The view transform turns the first into the second.

## Running a graph

**Evaluate**
: Compute values from a graph, with no side effects.

**Execute**
: Carry out **actions**, which are descriptions of side effects such as "write
this image to this path with these settings". An **output node** is a node
whose value is an action. Xpro only executes when asked to.
